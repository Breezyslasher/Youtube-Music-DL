Apple has the best coverage of the three, including older catalogue the others miss, and is the only source with per-word timing. It needs the media-user-token of a signed-in account with an active subscription (browser devtools → any amp-api request → the Media-User-Token header). Lyrics there are licensed content, so this stays inert until you set a token. The token is long-lived but not permanent - signing out, a password change or a lapsed subscription invalidates it - so test it here if Apple stops returning lyrics.
